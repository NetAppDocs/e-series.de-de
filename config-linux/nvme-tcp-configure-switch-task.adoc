= Konfiguration von Switches für E-Series Linux NVMe over TCP Hosts
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die Switches sind gemäß den Empfehlungen des Herstellers für NVMe über TCP zu konfigurieren. Diese Empfehlungen können sowohl Konfigurationsanweisungen als auch Codeaktualisierungen umfassen.

E-Series enthält keine spezifischen Vorgaben zu Ihrer Netzwerkkonfiguration. Eine Abstimmung mit Ihrem Netzwerkadministrator zur Auswahl der für Ihre Umgebung geeigneten Konfiguration ist empfehlenswert.

.Was kommt als Nächstes?
Nachdem Sie die Schalter konfiguriert haben, link:nvme-tcp-setup-host-side-task.html["Einrichten des NVMe Initiators über TCP auf dem Host"].
