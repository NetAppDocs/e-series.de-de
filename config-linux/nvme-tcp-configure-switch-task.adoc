= Die Konfiguration der Switches in E-Series - Linux (NVMe über TCP)
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die Switches sind gemäß den Empfehlungen des Herstellers für NVMe über TCP zu konfigurieren. Diese Empfehlungen können sowohl Konfigurationsanweisungen als auch Codeaktualisierungen umfassen.

E-Series enthält keine spezifischen Vorgaben zu Ihrer Netzwerkkonfiguration. Für Hinweise zur Auswahl der geeigneten Konfiguration für Ihre Umgebung wenden Sie sich bitte an Ihren Netzwerkadministrator.

.Was kommt als Nächstes?
Nachdem Sie die Schalter konfiguriert haben, link:nvme-tcp-setup-host-side-task.html["Der NVMe-Initiator über TCP wird auf dem Host eingerichtet."].
